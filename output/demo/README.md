# Demo output — real nested cut sheets + BOM

Generated by the pipeline from the **real** strandbeest parts in
[`../../input/demo/parts_raw`](../../input/demo/parts_raw):

- `sheet_01.dxf … sheet_09.dxf` — the nested cut sheets (2440×1220 mm), ready for a laser/CNC.
- `sheet_01.svg … sheet_09.svg` — the same, rendered for quick viewing.
- `BOM.csv` — cut-part quantities (×10 kits) + hardware list.

**How it was made:**
```bash
py pack_dxf.py     # with config.json: scale 6.0, 10 kits, 2440x1220 sheets
```
590 parts (12 unique × 10 kits) nested onto 9 sheets. Holes reset to real hardware sizes —
**6.5 mm** pivots and **8 mm** gear bores — independently of the ×6 scale.

The `scale: 6.0` here is a representative value (~hip-height beest). Set it to
`target_leg_mm / current_leg_mm` for your final build size and re-run.
